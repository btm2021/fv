  HOW TO USE THE FILTER IN PRODUCTION:
  1. At ATRBot signal, scan all ACTIVE (unswept) liquidity zones
  2. For BUY: check if any BSL (Buy Side Liq) is within 1.5% ABOVE entry
     → If YES: SKIP the trade (market will likely sweep BSL then drop)
  3. For SELL: check if any SSL (Sell Side Liq) is within 1.5% BELOW entry
     → If YES: SKIP the trade (market will likely sweep SSL then pump)
  4. BONUS: If safe liq (helping direction) < danger liq distance → take trade
